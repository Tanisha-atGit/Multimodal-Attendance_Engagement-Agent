Multimodal Attendance & Engagement Agent

📌 Overview

The Multimodal Attendance & Engagement Agent is an AI-based project designed to simplify attendance tracking and monitor student engagement in educational institutions. It aims to reduce manual work and make attendance management more efficient.

🎯 Objectives

- Simplify attendance management.
- Reduce manual attendance tracking.
- Monitor student engagement.
- Provide a user-friendly interface for educational institutions.

✨ Features

- User-friendly web interface.
- Attendance management.
- Student engagement monitoring.
- Organized data management.
- Easy-to-use application.

🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- Artificial Intelligence and Machine Learning concepts

🚀 Installation and Setup

1. Clone the Repository

git clone https://github.com/Tanisha-atGit/Multimodal-Attendance-Engagement-Agent.git

2. Open the Project Folder

cd Multimodal-Attendance-Engagement-Agent

3. Install Dependencies

pip install -r requirements.txt

4. Run the Application

python app.py

Open the local URL displayed in the terminal to access the application.
